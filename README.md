## Spotify Billboard 100 Playlist Generator

* Developed a Python application to extract Billboard Hot 100 chart data for a selected date using web scraping techniques with Beautiful Soup and Requests.

* Implemented data processing to retrieve song titles and match them with corresponding tracks available on Spotify.

* Integrated the Spotify Web API using Spotipy and OAuth 2.0 to securely authorize access to the user's account.

* Automated the creation of private Spotify playlists and the addition of matching tracks based on historical Billboard chart rankings.
